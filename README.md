# shdoors

Official website and digital catalog for **S.S.T. Doors** — Manufacturer & Wholesaler of Premium Wooden Doors, Teak Wood Doors, Flush Doors, and Plywood Doors based in Erode, Tamil Nadu, India.

## Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router DOM (v7)

## Features
- Premium architectural product catalog
- Dynamic category filtering & search
- Direct WhatsApp enquiry with pre-filled product details (`+91 90427 32565`)
- Quick call integration
- Fully responsive mobile navigation & sticky quick-action bar
- Interactive gallery with lightbox
- SEO optimized with OpenGraph meta tags & JSON-LD structured data

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
